Software icons displayed on the BTC Pavao Debian images page.

These are upstream project graphics, not generated replacement logos.
Pinned source-file URLs are recorded in sources.json. Upstream license texts
are included in licenses/. The source repositories contain the corresponding
artwork and source code. Artwork retains its upstream authorship and licensing.
The 7-Zip icon was converted from the upstream ICO container to PNG for browsers;
the other downloaded graphics are unchanged.
