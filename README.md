# btcpavao.github.io

Personal website hosted with GitHub Pages.

## Run locally

From the project root:

```bash
python3 -m http.server 5173
```

Then open:

- `http://localhost:5173/`

## Deploy

This repository is intended to be published as a GitHub Pages **user site**:

- Repository name: `btcpavao.github.io`
- Branch: `main`
- Folder: `/ (root)`
